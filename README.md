# Navi – Team 2 (SE 4351.001)

Navi is a voice-led indoor navigation concept for blind and low-vision users.
It confirms your location, takes a spoken destination, and guides you step by
step through mapped buildings.

**Live site:** https://jayden-boomer.github.io/SE4352.001-TeamWebsite/
